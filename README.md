
# Workshop Energy Cost Estimator

## What It Does
This Python program estimates the daily and monthly energy consumption of workshop appliances. It also calculates electricity costs using the tariff per kWh and checks whether the monthly cost is within a user’s budget.

## How to Run
1. Install Python 3.
2. Download `project.py` from this repository.
3. Open a terminal or command prompt in the folder containing the file.
4. Run: `python project.py`
5. Enter the number of appliances, each appliance’s power and daily usage hours, the electricity tariff, and the monthly budget when prompted.

## Sample Output
Using two appliances:
- 75 W used for 5 hours per day
- 100 W used for 3 hours per day
- Tariff: ₦250 per kWh

Daily energy: 0.675 kWh  
Monthly energy: 20.25 kWh  
Daily cost: ₦168.75  
Monthly cost: ₦5,062.50

## My Own Twist
The program compares the estimated monthly electricity cost with the user’s monthly budget and reports whether the cost is within budget.
